# camscan camera-vendor keywords (BLE side)

# One keyword per line. Matching is case-insensitive substring: a keyword
# matches if it appears anywhere in an advertised BLE name OR in the vendor
# name that a BLE company-ID resolves to. Blank lines and lines starting with
# '#' are ignored.
#
# The philosophy (from the project handoff): match on vendor NAME/keyword, not
# a brittle list of raw company-ID numbers. Company IDs get resolved to a
# vendor name first (see company_ids.txt), then matched here like any name.

# sub-brands. Add freely as you encounter new ones -- editing this file needs
# no code change and no reflash.
